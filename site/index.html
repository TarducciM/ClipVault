what it does

Nothing you copy should just vanish.

No accounts, no cloud sync, no telemetry. Install it, learn the hotkey, and it stays out of your way otherwise.

∞

Every copy, remembered

Text, images, and file paths all land in one running history, so nothing you copied a few minutes ago is gone for good.

⌃⇧V

One hotkey, everywhere

A small popup opens right next to your cursor in any app — no digging through a tray icon first.

/

Search as you type

Jump straight to the entry you need instead of scrolling — search matches text content and file names alike.

PIN

Pin what matters

Favorite entries stay put at the top of the list instead of scrolling out of reach with everything else.

LOCAL

Fully local, always

No account, no cloud sync, no telemetry. Your clipboard history is stored on your machine and never leaves it.

MBs

A few megabytes, not a few hundred

Built on Tauri: a Rust backend and your system's own webview, so it starts instantly and idles near zero.
